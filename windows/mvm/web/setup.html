Налаштування

Програма лише читає дані батареї. Керування — в офіційному застосунку Marstek.

Дашборд →
Перший запуск: знайдіть батарею або введіть її IP-адресу, виберіть регіон і чергу — і натисніть «Зберегти».

1. Батарея

Увімкніть Open API у застосунку Marstek (порт 30000) і закріпіть за батареєю IP у роутері.

    2. Графік відключень

    Чергу можна дізнатися на сайті свого обленерго за адресою.

    3. Резервний вихід і опитування

    Світло вважається відсутнім, коли потужність резервного виходу перевищує поріг. Середнє споживання дає прогноз запасу одразу (інакше — після першого відключення). Батарея не любить частих запитів: не ставте опитування менше 30 с, якщо її вже опитує інший сервер.

    4. Сповіщення Windows

    Доступ для телефона

    Дашборд стане доступним у домашній мережі за токеном (телефон, Android-застосунок у режимі «Сервер»). Windows може спитати дозвіл брандмауера — дозвольте лише для приватних мереж.
